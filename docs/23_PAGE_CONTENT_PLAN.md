# 페이지 콘텐츠 계획

## 인증 페이지

### 로그인

- 재경닷컴 그룹웨어 브랜드와 임직원 전용 안내
- 이메일, 비밀번호, 표시·숨김, 로그인 상태 유지
- 로그인 버튼, 비밀번호 재설정, 가입 신청
- 승인 전 계정 안내와 접근 가능한 오류 영역
- G0–G1에서는 제출 시 실제 요청 없이 연동 전 상태를 안내한다.

### 가입 신청

- 이름, 회사 이메일, 연락처, 비밀번호, 비밀번호 확인
- 부서, 직급 또는 직책 선택
- 선택값은 향후 Supabase 조직 데이터로 교체할 정적 옵션
- 제출 시 실제 회원을 생성하지 않고 연동 전 상태를 안내한다.

### 승인 대기

- 신청 접수와 관리자 승인 후 사용 가능 안내
- 이메일 표시 영역, 로그인으로 돌아가기, 경영지원부 문의 안내
- URL이나 저장소에 개인정보를 영구 보관하지 않는다.

### 비밀번호 재설정

- 이메일, 요청 버튼, 로그인으로 돌아가기
- 성공·오류 메시지 영역
- G0–G1에서는 메일을 발송하지 않는다.
