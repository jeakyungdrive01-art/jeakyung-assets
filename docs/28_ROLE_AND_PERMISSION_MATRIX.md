# 역할과 권한 매트릭스

## 역할

1. 최고 관리자
2. 관리자
3. 부서장
4. 팀장
5. 직원

역할은 직급·직책과 별개다. 한 사용자의 최종 권한은 역할, 소속 조직, 리소스별 정책과 명시적 예외를 서버에서 조합해 판정한다.

## 판정 원칙

- 메뉴를 숨기는 것은 편의 기능이며 보안이 아니다.
- 클라이언트, 서버 함수와 Supabase RLS가 동일한 권한 개념을 사용한다.
- 기본값은 거부이며 명시적으로 허용된 작업만 수행한다.
- 최고 관리자 권한 부여·회수, 최종 삭제와 권한 변경은 재인증과 감사 로그를 요구한다.
- 관리자는 자신의 권한보다 높은 역할을 부여할 수 없다.
- 관리자 메뉴는 향후 Auth Context에서 전달받은 권한으로 표시한다. G0–G1에서는 가짜 역할을 만들지 않는다.

게시판별 권한은 [`29_BOARD_SYSTEM.md`](29_BOARD_SYSTEM.md), 서버 보안은 [`31_SECURITY_AND_RLS.md`](31_SECURITY_AND_RLS.md)를 따른다.
